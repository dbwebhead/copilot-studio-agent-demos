1. Create or choose a Team → Add channel **marketing-ops** (Standard).
2. Add tabs:
   - Tasks by Planner and To Do → plan “Giving Tuesday 2025”
   - SharePoint → pin “Campaign Summary” page
   - SharePoint Lists → pin “Campaign Decisions”
3. Grab IDs for flows: Channel … → **Get link to channel** (extract groupId and channelId).
4. Post a welcome message with 2–3 sample prompts.
